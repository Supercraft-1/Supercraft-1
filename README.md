# Supercraft

**Mechanical design · Experimental instrumentation · Mechatronics**

中国农业大学机械工程专业硕士在读。关注机械结构、受控激励、传感器与数据采集，以及声振信号分析。我希望把机构、硬件和软件作为一套可验证的系统来设计。

M.Eng. student in Mechanical Engineering at China Agricultural University. My work focuses on mechanism design, measurement systems, embedded acquisition, and vibration-signal analysis.

## 关注方向 / Focus

- **机械与仪器：** 机构设计、三维建模与装配、实验装置集成。
- **采集与控制：** STM32、传感器、运动控制和上位机通信。
- **数据与软件：** MATLAB / Python 信号分析，C / C++ 桌面与嵌入式开发。
